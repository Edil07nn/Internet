# InternetSpeed — Интернет жылдамдығын өлшеу журналы

## 1. Жоба туралы

Бұл жобаның мақсаты — әртүрлі орындардағы интернет жылдамдығын тіркеу және талдау. Бағдарлама интернет жылдамдығын (Mbps), ping мәнін (ms), өлшеу күнін және өлшеу орнын сақтайды. Сонымен қатар, ең жоғары және ең төмен жылдамдықты анықтап, баяу интернет өлшемдерін табады.

## 2. Қолданылған технологиялар

- Java
- IntelliJ IDEA
- Git және GitHub
- Speedtest

## 3. Жобаның құрылымы

- `InternetSpeed.java` — интернет өлшемінің мәліметтерін сақтайды.
- `InternetSpeedLog.java` — өлшемдерді сақтайды және статистиканы есептейді.
- `InternetSpeedTestDrive.java` — бағдарламаның әдістерін тексереді.
- `InternetSpeedApp.java` — пайдаланушы мәзірін басқарады.
- `evidence/` — Speedtest нәтижелерінің скриншоттары.
- `uml.png` — UML диаграммасы.

## 4. Интернет өлшемдері

Төмендегі кестеге өзің өлшеген нақты нәтижелерді енгіз.

| Күні (КК.АА) | Орын | Жылдамдық (Mbps) | Ping (ms) |
|---|---|---:|---:|
| Өз нәтижеңді енгіз | Үй | Өз мәнің | Өз мәнің |
| Өз нәтижеңді енгіз | Университет | Өз мәнің | Өз мәнің |

## 5. Деректерді жинау

Интернет жылдамдығы Speedtest сервисі арқылы өлшенеді. Өлшеулер әртүрлі күндерде және әртүрлі орындарда жүргізіледі. Әр өлшеу кезінде жүктеу жылдамдығы мен ping мәні жазылады. Нәтижелер бағдарламаға енгізіліп, салыстырылады.

## 6. Бағдарламаны іске қосу

1. Жобаны IntelliJ IDEA арқылы ашу.
2. Java файлдарының қателерсіз компиляциялануын тексеру.
3. `InternetSpeedTestDrive` класын іске қосып, тест нәтижелерін тексеру.
4. `InternetSpeedApp` класын іске қосып, мәзірді пайдалану.
